## 세션 중 되짚은 결정 2건

### T1 상향 — 최소 투입 → 중간 투입

Q1에서 최소 투입(정적 한 장·시안 없이·며칠)으로 정했으나, Q6~Q8에서 손 연출 컨셉이 확정되며 제약을 다시 잡았다.

| | |
|---|---|
| 충돌 지점 | 손 이미지 20장 제작과 JS 스크롤 연출은 "기존 자산 재사용" 범위 밖 |
| 처리 | 충돌을 알리고 **1회 재확인**(Q7) → 사용자가 품질 차이를 물음 → 비교표 제시 후 재제시(Q8) |
| 결과 | T1을 중간 투입(1~2주)으로 갱신. 투입을 **집중할 곳(히어로 손 연출)과 아낄 곳(본문은 기존 자산 인용)**을 구분해 기록 |

### T5 범위 축소 — "JS 없음"의 적용 대상

Q5에서 "JS 없음"으로 정한 것이 사이트 전체로 읽힐 여지가 있었다. Q8에서 사용자가 원래 의도를 밝혀 범위를 좁혔다.

```
이전 해석  사이트 전체에서 JS를 쓰지 않는다
확정 해석  스킬 사용 예제(S6 데모 4컷)의 시각적 제시에만 적용된다
           → 히어로 손 연출과 언어 전환·탭에는 JS를 쓴다
```

## 확정된 것의 골자

**연출** — 히어로에서 양쪽 손이 모여 쥐고, 빛이 터지고, 하단으로 내려가 받침으로 펼쳐져 그 위에서 시연이 흐른다. 이미지 20장 내외 시퀀스를 JS로 스크롤에 연동한다.

**구현** — HTML 한 장 + 공유 CSS 한 벌 + JS(언어 전환 · 손 연출 · 도메인 표 탭). 빌드 없음. `web/` 폴더에 두고 정적 호스팅에 연결, 주소는 `grip-it.work`.

**시각** — 밝은 테마 전용. 난색(햇볕)은 분위기, 한색(딥 네이비·밝은 블루)은 정보. 본문은 좁게, 데모·표는 넓게, 히어로는 전체 폭.

**절제** — 데모 4컷 정적 · 본문 모션은 S1 네 장면만 · 다크 모드 없음 · 계측 없음 · 접근성은 기본값.

## 근거가 함께 기록된 결정들

단순 선택으로 끝내지 않고 판단 근거를 문서에 남긴 항목이다. 이후 회차에서 같은 논의가 되풀이되지 않게 한다.

| 결정 | 함께 기록한 근거 |
|---|---|
| 한·영 병행 (T3) | 시각 자산은 한 벌, 두 벌로 만드는 것은 카피뿐 — 최소 투입과 충돌하지 않는 방식 |
| 4컷 나란히 (T5) | 인터랙션을 잃는 대신 절차 전체가 한 흐름으로 남는다. 잃은 몫은 컷 사이 전환 문장으로 벌충 |
| 밝은 테마 전용 (T7) | 손 시퀀스가 밝은 바탕 전제라 두 벌이면 시퀀스를 다시 제작해야 함 |
| 한글 고정폭 (T8) | 기록부 표의 세로 정렬이 여기 달림. 대체 서체도 고정폭이어야 함 |
| 선도형 SVG (T9) | 히어로가 은유를 맡으므로 본문은 구조만. 둘 다 화려하면 둘 다 흐려짐 |
| 계측 안 함 (T13) | 표는 남긴다 — "이 요소가 설치 명령 복사에 기여하는가"를 묻는 잣대로 계속 씀 |
| 폭 구분 (T14) | 폭이 바뀌는 것 자체가 "설명 / 보여주기"의 신호. 소제목 없이 구조가 읽힘 |
| 도메인 표만 탭 (T15) | 도메인 표는 "개발자용 아님"을 증명하는 자리, 기록부 블록은 형태 자체가 메시지 |
| S1 모션 (T16) | 장식이 아니라 속도 조절. 한 번에 보이면 목록으로 읽히고, 하나씩 나오면 멈추게 됨 |
| 저장소 안 `web/` (T17) | 스킬이 바뀔 때 페이지를 같은 커밋에서 고칠 수 있어 인용 규칙과 어긋나지 않음 |
